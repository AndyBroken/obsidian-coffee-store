# Obsidian Coffee Roasters — Premium Package (Concept)

Full e-commerce storefront for a luxury specialty coffee brand.

**Features**
- Shop with search, category / roast / origin filters, price slider, sorting, active-filter chips
- Product pages: size & grind variants, one-time vs. subscribe-and-save pricing, quantity, zoomable gallery, tabs (details, brew guide, reviews), stock indicator, related products
- Slide-out cart drawer: quantities, free-shipping progress bar, upsell, saved in localStorage
- 3-step checkout: validated address form, shipping methods, promo codes (`WELCOME10`), tax, order confirmation (demo mode — no real payment)
- Subscription quiz that recommends a coffee and delivery schedule
- Dark / light theme toggle, animated hero, marquee, review slider, scroll reveals, fully responsive

**Tech:** HTML5, CSS3 (custom properties, grid), vanilla JavaScript — no frameworks. Ready to connect to Shopify / Stripe.

*Concept / demo project — Obsidian is a fictional brand. No payments are processed.*
